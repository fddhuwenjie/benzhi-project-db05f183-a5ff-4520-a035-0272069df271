# DialectCorpusReleaseGate

DialectCorpusReleaseGate 是面向方言语音资料整理团队的语料标注批次质量放行工作台。它围绕一条受控流程工作：批次建档、冻结规范、条目范围与来源摘要预检、双人独立标注、分歧裁决、确定性抽样审计、限定返修、定向复审，以及不可变发布清单与摘要验证。

服务由 Go 直接提供原生 HTML、CSS、JavaScript 工作台，不需要 Node 构建链。浏览器访问 `/workbench` 即可在单个批次视图内完成主要流程，并查看字段级一致率、低一致待办、标注员负载、审计轮次通过率和返修状态。同源 JSON API 使用 `expected_revision` 防止陈旧覆盖，使用 `request_id` 保证成功与确定性失败响应均可幂等重试。

## 构建

```sh
go build ./cmd/server
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`，数据写入 `./data`：

```sh
go run ./cmd/server
```

可显式指定监听地址和数据目录：

```sh
go run ./cmd/server -addr=127.0.0.1:19123 -data-dir=./data
```

也可以设置 `PORT` 为端口号；未显式修改 `-addr` 时，服务会绑定 `127.0.0.1:<PORT>`。服务拒绝非回环监听地址。

## 测试与自检

运行全部单元与 HTTP 边界测试：

```sh
go test ./...
```

运行真实回环 HTTP 自检：

```sh
go run ./cmd/server -selftest -selftest-timeout=12s -addr=127.0.0.1:19081
```

自检使用临时数据目录，实际启动 HTTP 服务并驱动完整业务流程。流程会制造一次审计失败，验证只能返修命中范围，再执行定向复审、发布清单冻结和摘要重算；完成后服务会主动关闭并自行退出。

## 数据与完整性

每个批次的聚合快照、幂等原始响应和只追加事件帧保存在同一个原子替换文件中。事件帧包含连续序号、批次修订、前序摘要与自身摘要。服务启动时校验整个摘要链，发现损坏时隔离对应批次且不会静默修复。发布清单按条目稳定排序并另存为不可变文件，同时保留在终态聚合中用于恢复与验证。

发布验证会从当前快照、不可变清单和事件链重新计算规范基线摘要、清单总摘要，并确认清单记录的事件链摘要等于发布事件后的实际链末端摘要。验证失败时响应会区分 `manifest`、`rubric`、`event_chain` 组成，并列出内容不一致的 `item_id`。
